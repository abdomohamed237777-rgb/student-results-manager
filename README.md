# نظام إدارة النتائج

مشروع ويب لإضافة الطلاب وحساب متوسط درجاتهم، مع تفعيل لجنة الرأفة للطلاب الذين يقع متوسطهم بين 40 و49.

## ملفات المشروع
- `index.html`: صفحة التطبيق.
- `css/style.css`: تنسيق وتصميم الصفحة.
- `js/main.js`: كلاس الطالب والتحقق من البيانات وإضافة الطلاب وتقرير لجنة الرأفة.

## طريقة التشغيل
افتح ملف `index.html` باستخدام متصفح الإنترنت.

## المفاهيم المستخدمة
- HTML وBootstrap وCSS.
- JavaScript Classes وPrivate Fields وGetters وSetters.
- `throw new Error` و`try...catch`.
- DOM و`getElementById`.
- `filter` و`map` و`reduce` وTemplate Literals.
